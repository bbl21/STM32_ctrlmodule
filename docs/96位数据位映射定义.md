# 96 位数据位映射定义

## 硬件架构

```
PC CDC (12字节=96位)
  → STM32F103 SPI1 (6×16位, MSB first)
  → 74HC595 移位寄存器链 (串转并, 96位并行输出)
  → 3× D-sub 37芯接插件 (每个: 5×GND + 32×数据线)
  → 子模块 J30J 接插件
```

### D-sub 37 芯接插件引脚定义

每个 D-sub 37 芯：
| 引脚范围 | 功能 |
|---------|------|
| 1-5     | GND (共地) |
| 6-37    | 32 位数据线 |

---

## 总线模块清单

| 模块 | 数量 | 控制信号 | 说明 |
|------|------|---------|------|
| 15芯接收变频模块 | 2个 | 10路/个 | 每个控制4个天线，KxA=V极 KxB=H极 |
| 25中频模块 | 3个 | 15路/个(+3备用) | 对应8天线+1参考通道 |
| 参考通道开关 | 1个 | 2路 | SP4T (KCKA, KCKB) 四选一 |

### 模块-天线对应

**15芯接收变频模块 1** — 天线 A, B, C, D
| J30J 信号 | 位置 | 控制对象 | 直通 |
|-----------|------|---------|------|
| K1A/K1B | 天线1 | 天线 A V/H | 无 |
| K2A/K2B | 天线2 | 天线 B V/H | K2ZT |
| K3A/K3B | 天线3 | 天线 C V/H | K3ZT |
| K4A/K4B | 天线4 | 天线 D V/H | 无 |

**15芯接收变频模块 2** — 天线 E, F, G, H
| J30J 信号 | 位置 | 控制对象 | 直通 |
|-----------|------|---------|------|
| K1A/K1B | 天线1 | 天线 E V/H | 无 |
| K2A/K2B | 天线2 | 天线 F V/H | K2ZT |
| K3A/K3B | 天线3 | 天线 G V/H | K3ZT |
| K4A/K4B | 天线4 | 天线 H V/H | 无 |

**25 中频模块 ×3** — 每模块对应一组 IF1/IF2/IF3 通道
| J30J 信号 | 数量 | 说明 |
|-----------|------|------|
| KIF1x (11/12) | 1路联动 | IF1 宽窄带选择，11入12出联动 |
| KIF2x (21/22) | 1路联动 | IF2 宽窄带选择 |
| KIF3x (31/32) | 1路联动 | IF3 宽窄带选择 |
| iATT1/2/4 (i=1,2,3) | 9路 | IF1/2/3 衰减器 0-7dB |
| iATT8 (备用) | 3路 | IF1/2/3 衰减器扩展 8dB |

**参考通道**
| SP4T 信号 | 编码 | 说明 |
|-----------|------|------|
| KCKA, KCKB | 11/10/01/00 | 参考通道 1/2/3/4 四选一 |

## IF 宽窄带联动

KIFx1 和 KIFx2 应联动控制：

| KIFx1 (入) | KIFx2 (出) | 模式 |
|-----------|-----------|------|
| 0 (窄带)  | 1 (窄带)   | 窄带 |
| 1 (宽带)  | 0 (宽带)   | 宽带 |
