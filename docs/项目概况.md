# 射频前端控制模块 — 项目概况

## 1. 项目简介

本系统是 **8~18GHz 射频前端** 的配套控制模块，用于天线选择、极化切换、信号路由、IF 衰减调节和参考通道选择。整个系统由 **STM32F103 控制板（硬件 + 固件）** 和 **Qt6 PC 控制软件（上位机）** 组成，通过 USB CDC（虚拟串口）通信。

### 核心功能

| 功能 | 说明 |
|------|------|
| 天线选择 | 8 路天线 (A-H) 独立选通，每路 V/H 极化可切换 |
| 直通模式 | 天线 B/C/F/G 可选直通（跳过变频级） |
| 下变频控制 | 三组 25中频模块，每通道窄/宽带选择 + 0-15dB 衰减 |
| 参考通道 | 外部 4 路参考信号经 SP4T 4选1 注入第三中频模块 |
| 本振驱动 | 模块 D 为三个 25中频模块提供本振信号 |

## 3. 硬件设计

### 控制板 (STM32F103)

主控芯片 **STM32F103C8T6**，通过 SPI 驱动 12 片 74HC595 移位寄存器链，产生 96 位并行控制信号，经三路 D-sub 37 芯连接器输出至各射频模块。

#### 引脚分配

| 引脚 | 功能 | 连接 |
|------|------|------|
| PA5 | SPI1 SCK | 74HC595 SHCP (移位时钟) |
| PA7 | SPI1 MOSI | 74HC595 DS (串行数据) |
| PB3 | 输出使能 | 74HC595 OE (低有效) |
| PB5 | 锁存信号 | 74HC595 STCP (上升沿锁存) |
| PA11/USB_DM | USB 差分负 | USB CDC |
| PA12/USB_DP | USB 差分正 | USB CDC |

#### 74HC595 链结构

- 12 片 74HC595 级联，每片 8 位 → 96 位并行输出
- 每路 D-sub 37 芯连接器分配 32 位数据 + 5 位 GND
- 上电默认 OE 为高（输出高阻），初始化后拉低使能

## 4. 固件设计 (STM32F103)

### 目录: `ctrl_module_v4_code/`

| 文件 | 功能 |
|------|------|
| `Core/Src/main.c` | 主循环：轮询 `data_received`，执行 nibble swap + 字节重排，SPI 发送，PB5 锁存 |
| `USB_DEVICE/App/usbd_cdc_if.c` | CDC 接收回调 `CDC_Receive_FS()`，接收 12 字节后置标志 |
| `Core/Src/stm32f1xx_hal_msp.c` | SPI1 引脚初始化 (PA5=SCK, PA7=MOSI) |
| `Core/Src/stm32f1xx_it.c` | USB 中断处理 |

### 核心算法

从 USB CDC 接收 12 字节后，固件执行 nibble 交换和字节重排以补偿 SPI/595 的硬件位序：

```c
// 12字节 → 3组×4字节 → nibble交换 → 组内逆序 → 6×16位 SPI
for (int i = 0; i < 3; i++) {
    b0 = reverse_nibble(recv[i*4]);      // 高低4位交换
    b1 = reverse_nibble(recv[i*4+1]);
    b2 = reverse_nibble(recv[i*4+2]);
    b3 = reverse_nibble(recv[i*4+3]);
    spi_buffer[i*2]   = (b3<<8) | b2;    // 字内字节逆序
    spi_buffer[i*2+1] = (b1<<8) | b0;
}
// SPI 发送 6×16 位，PB5 脉冲锁存
```

**特性：PC 输入 = 595 输出 (输入即输出)**，nibble 交换 + 字节重排补偿了 SPI/595 的硬件位序。

### 工作流程

```
上电 → 初始化(HAL/SPI/USB) → PB3=0 使能输出 → 主循环:
  ┌─ CDC 收到 12 字节?
  ├─ 是 → nibble交换 + 字节重排 → SPI 发送 → PB5 脉冲锁存
  └─ 否 → 继续轮询
```

## 6. 通信协议

### USB CDC (虚拟串口)

| 参数 | 值 |
|------|------|
| 接口 | USB 2.0 Full-Speed (12 Mbps) |
| CDC 类 | 抽象控制模型 (ACM) |
| 数据格式 | 12 字节固定帧，96 位控制字 |
| 方向 | 单向：PC → STM32（数据下发） |
| 波特率 | 虚拟串口忽略，USB 原生速率 |

### 数据帧

```
位 0-95: 96 位控制字
字节 0-11: 大端序，每字节低位在先 (因 nibble swap 补偿)
```

### 固件处理

```
USB 12 字节 → nibble 交换 → 字节重排 → 6 × 16 位 SPI → 595 锁存
```

